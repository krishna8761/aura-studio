## 🛠️ Elite Technology Stack

*   **Core Logic:** [React 19](https://react.dev/) & [TypeScript](https://www.typescriptlang.org/) (Strict compilation enabled).
*   **Animations:** [Framer Motion](https://www.framer.com/motion/) (Cast parameters, spring phys paths, scroll-into-view triggers).
*   **Icons:** [Lucide React](https://lucide.dev/) (Polished clean SVG vectors).
*   **Styling:** Custom [Tailwind CSS v4](https://tailwindcss.com/) with dedicated HSL coordinate neon spotlight variables.
*   **Build Pipeline:** [Vite v8](https://vite.dev/) (Sub-second build times).

## 🚀 Local Operations & Installation

### 1. Project Setup
```bash
# Clone the repository
git clone <your-repository-url>

# Navigate into the project workspace
cd react-app

# Install all npm dependencies
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) on your browser to enjoy the high-end coordinate spotlights and click interactions!

### 3. Compile Production Bundle
```bash
npm run build
```
Generates a highly compressed, SEO-optimized production bundle under `/dist` in less than **750ms**!
